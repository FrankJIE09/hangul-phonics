发音模式
  • 发音方式以「韩语原音」为默认。本页把韩文原字交给浏览器，并把 lang 设为 ko-KR，由引擎自己路由音色。即使系统语音列表里没有列出 ko-KR，大多数浏览器/系统仍能正确朗读韩文（Edge 的在线神经音色、Windows OneCore 音色、Safari 的 Yuna 常常不出现在列表里）。
  • 三种发音模式。「自动（韩语原音）」与「韩语原音」都是韩文原字朗读；「中文近似音」改用中文音色念近似汉字（ㄱ→嘎、ㄷ→搭、ㅂ→巴），彼此可区分，但整音节（如 넉）无法准确朗读，听力题会自动关闭。如果听着不对，用自检面板里的「A/B 对比」按钮当场判断，再一键切换。
  • 怎么装韩语语音包。Windows：设置 → 时间和语言 → 语言和区域 → 添加语言 → 한국어 → 勾选「语音」→ 安装后重启浏览器。macOS：系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音 → 한국어 → 下载「Yuna」（macOS 通常已内置，Safari 与 Chrome 都能直接用）。Chrome / Edge 联网时通常还能拿到在线音色（Google 한국의 / Microsoft SunHi 等），可在自检面板的下拉框里手动指定。
  • macOS 使用说明。本页是纯前端单文件，Safari / Chrome / Edge 都能用。Safari 的额外限制：朗读必须由真实点击或按键触发（已自动处理，含首次手势解锁），所以不要期待「打开页面就自动读」；另外 Safari 对 file:// 的 localStorage 支持不稳定，建议用下面的线上地址或 python3 -m http.server 打开，避免学习记录存不下来。
  • 单字母直接念字母本身。与桌面跟读卡相同：点 ㄱ 就念「ㄱ」，点 ㅏ 就念「ㅏ」，不再预先合成 가 / 아。完整音节请到拼读工作台组合后播放。
  • ㅓ vs ㅗ 最容易混。ㅓ 是 /ʌ/，双唇不圆；ㅗ 是 /o/，双唇必须收圆前突。TTS 有时会把 ㅓ 读得偏圆。
  • ㅐ / ㅔ 已基本合并。现代首尔音里两者几乎同音；ㅙ / ㅚ / ㅞ 也趋同，听到相同读音是正常的。
  • 紧音 ㄲ ㄸ ㅃ ㅆ ㅉ 是「喉部绷紧、不送气」，不是送气音。TTS 可能读成松音或送气音，听的时候注意短促、有力。
  • 中文近似音模式下，近似字一定两两不同。松音一声平缓（ㄱ→嘎、ㄷ→搭、ㅂ→巴），紧音四声短促（ㄲ→尬、ㄸ→大、ㅃ→爸）。顶栏「🔊」标签会显示实际送进语音引擎的内容（韩文原字或近似汉字），可用来核对是哪种模式在发声。
  • 看到页脚构建版本号对不上，就是缓存。如果修完仍听到旧行为，按 Ctrl/⌘ + Shift + R 强制刷新（GitHub Pages 有 CDN 缓存）。
  • 받침 ㄱ ㄷ ㅂ 读不爆破的 [k̚ t̚ p̚]：只做口型、不放出气流，不要额外加「으」。
  • ㅢ · ㅚ · ㅟ 有多个变体读音（如 ㅢ 在助词中常读 /e/），TTS 选择哪一种因语音包而异。
  • IPA 是宽式近似标注。没有覆盖连音、紧音化、鼻音化、流音化等音变；拼读工作台展示的是「字母层」读音。

# 韩语谚文拼读练习 · Hangul Phonics

一个纯前端的韩语谚文字母拼读学习工具，对标英文 natural phonics 练习网站。单文件实现（HTML + CSS + JavaScript），无后端、无外部依赖、无 CDN。

**在线访问**：https://frankjie09.github.io/hangul-phonics/

## 功能

- **元音区 / 辅音区**：21 个元音（单元音、y 系列、w 系列）+ 19 个辅音（松音、送气音、紧音、鼻音/流音），每块包含韩文字符、IPA、英文近似音标、中文嘴型提示。
- **发音**：点击字母即播放，支持韩文 두벌식 键盘快捷键（如 `r` = ㄱ、`k` = ㅏ、`⇧r` = ㄲ），每个音可重复播放。
- **拼读工作台**：选初声 + 中声，可加받침（收音），自动拼成韩字并显示罗马音与 IPA，一键播放。
- **练习模式**：随机出题，「看字选组合」与「听音选字母」两种题型，自动统计正确率。
- **复习面板**：听过的字母、练过的音节自动保存到 localStorage，下次打开仍在。
- **发音自检面板**：列出系统可用语音、当前生效音色、最近朗读文本与错误，支持指定语音。
- **夜间模式**、移动端 / 桌面端自适应、字母对照表。

## 发音说明

全部使用浏览器内置 Web Speech API（`ko-KR`）。

如果系统没有安装韩语音色，浏览器会静默改用默认音色（通常是中文）去念韩文，听起来像「点了这个字却发出别的音」。页面顶部会自动提示，可在「发音引擎自检」面板中：

- 查看当前可用语音
- 切换发音模式（自动 / 强制韩语音色 / 中文近似音）
- 手动指定某个在线 `ko-KR` 音色

安装韩语语音包：

- **Windows**：设置 → 时间和语言 → 语言和区域 → 添加语言 → 한국어 → 勾选「语音」
- **macOS**：系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音 → 下载「韩语（Yuna）」
